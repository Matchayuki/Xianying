## 一、为什么做 EchoGlow

### 它不是"不想说"，是"说不出来"

重度抑郁和焦虑的低谷期，常伴随一种状态——精神医学里叫**精神运动性抑制**（说人话：主管情绪的那部分大脑过载了，思维和动作的节奏一起慢下来）。主观上痛苦巨大而清晰，客观上却喉咙发紧、思维粘稠，没办法向外发出一个准确的求救信号。

这就是**失语**。它不是沉默，是**发不出去**。

这个项目的起点很私人：作者是哲学系硕士研究生，身边不少朋友、也包括自己，都经历过这种失语。

### 现有的帮助，常常是第二次伤害

市面上的心理健康产品，基本是两条路：

- **数据打卡**——今天心情几分？连续记录多少天？
- **说教和鸡汤**——要加油、要积极、要学会接纳自己。

对一个正处于失语状态的人，这两条路都在要求他"再努力一点"。而那种居高临下的审视，恰恰会加重他本来就快撑不住的无力感。

> 第一版文本跑出来时，虽然逻辑通顺，却塞满了"认知过载""代偿机制""系统启动成功"这类冷漠的学术黑话。**这种居高临下的机器说教，对正处于失语和痛苦中的人来说是二次伤害。**

### 所以 EchoGlow 只做两件事

### 双轨：同一份痛苦，两种语言

| | 亲友卡 | 医生卡（就诊前整理） |
|---|---|---|
| **用的是** | 感性的语言 | 理性的语言 |
| **解决** | 害怕被误解、害怕那种要解释半天的社交消耗 | 坐在医生面前时，说不清自己的躯体症状 |
| **关键约束** | 每张卡必须包含**一种明确的行动**，不能让收件人看完不知道该做什么 | 只整理事实，不做量表、不下结论、不显得有临床效力 |
| **举例** | 「不用解决问题，陪我待十分钟。」「暂时不用回复，我只是想让你知道。」 | 持续多久、频率如何、是否在恶化、睡眠进食与日常功能、当前用药变化、这次最希望医生帮什么 |

## 二、它能做什么

| 功能 | 说明 |
|---|---|
| **十种情绪材质** | 雾层、黏连体、褪色残影、细碎干扰、密实重物、悬浮泡影、岩石层理、空洞负空间、水下折射、玻璃断面。每种有独立的运动方式；压迫感影响视觉尺度；系统开启"减少动态效果"或手动暂停时，画面会完全停住 |
| **通感诗译** | 每种质感包含多种开头与收尾，结合附加情绪生成克制的感官白描；可以「换一种说法」，也可以直接复制 |
| **双轨转译卡** | 亲友卡可选安静陪伴 / 陪着待一会儿 / 文字沟通 / 具体帮个忙；医生卡只整理填写内容。两种卡都可手动编辑、保留独立草稿，并导出为 PNG 便笺 |
| **呼吸引导** | 轻缓（4/6）与经典（4/4/4）两种节奏；开始、暂停、继续、重置；可选海浪声与阶段提示音。切换页面或离开浏览器自动暂停 |
| **本地保存** | 旧版记录迁移、JSON 导出、二次确认清除。**不同域名的浏览器存储互不共享**——线上新域名读不到 GitHub Pages 或本地文件的旧记录 |

**3.0 相比旧版的关键改进：**

- 「想消失」触发确定性的安全确认，高风险内容**不会被随机诗句省略**
- 亲友卡默认给出明确回复动作，支持系统原生分享
- 医生卡改为「就诊前事实摘要」，增加日常功能影响字段
- 默认不持久保存；用户可自行开启本地保存，并获得**共享设备与明文导出提醒**
- 呼吸练习增加风险提示，并提供**不需要关注呼吸**的落地练习
- 首屏只展示五种常用质感，其余折叠；**选择不再自动生成文字**

### 那场"挑刺"，是 3.0 的起点

一句评审把整个项目拉回了地面：

> **EchoGlow 现在是一个视觉完成度很高的概念样机，但还不是能放心交给真实脆弱用户使用的心理产品。最大缺陷不在审美，而在——它接住了情绪，却没有接住风险。**

### 关键决策：每一处改动都对应一句具体的否定

| 收到的反馈 | 决策 | 为什么这么改 |
|---|---|---|
| 「整个 html 应用差强人意」 | 先修工程问题，再谈美学 | 刷新覆盖记录、复制失败却提示成功——这类 Bug 会直接摧毁信任，比"不好看"严重得多 |
| 「做个备份，然后大刀阔斧地改，美术也可以大改」 | 完整备份后整体重塑，不打补丁 | 视觉是入口，补丁堆不出质感 |
| 「需要完全重塑情绪显影的视觉呈现，质感要一致」 | 十种独立材质，各自独立的运动方式 | 廉价屏保感的粒子，承载不起"被看见"这件事 |
| 「褪色、噪点，尤其是沉重，效果太差」 | 三个重做 | 名不副实的材质，比没有更糟 |
| 「噪点根本就不是噪点，胶水也不太行」 | 噪点去掉波形改独立颗粒；胶水加拉开、拉丝、下垂、回缩 | 用户说的是**名实不符**，不是"不够好看"——要改的是物理，不是配色 |
| 「双轨传译太生硬」 | 标签转日常表达，去掉报数、模板腔和感谢套话 | 生硬的关心比不关心更伤人 |

## 四、它不做什么

- **不提供诊断、治疗或紧急服务。** 这是工具，不是医疗服务。
- **不做心理量表，不输出任何分数或评估结论。** 医生卡只整理你填写的内容。
- **呼吸练习有适用边界。** 出现头晕、胸痛、呼吸困难请立即停止；也提供不需要关注呼吸的替代练习。
- **默认不持久保存。** 你可自行开启本地保存，届时会收到共享设备与明文导出的提醒。
- **导出的 JSON 与 PNG 是明文。** 不要发到不放心的地方。
- **不同域名的浏览器存储互不共享。** 线上新域名读不到旧域名的记录。
- **无第三方脚本、字体或图片请求**，也不发任何埋点。断网也能用。

## 五、运行与部署

纯静态网页，**打开 `index.html` 就能用**，不需要构建、不需要服务器、不需要安装任何依赖。

（唯一例外：复制功能需要 HTTPS 或 localhost 环境，以及浏览器授权。）

需要 Node.js 18 或以上，但**不需要 `npm install`**：

```sh
node test.cjs    # 12 项核心逻辑检查
node build.cjs   # 构建，产物在 dist/
```

`dist/` 是可以直接部署的静态输出。

### 文件分工

| 文件 | 职责 |
|---|---|
| `index.html` | 页面结构与文案 |
| `core.js` | 输入校验、诗译生成、卡片内容、记录存取与迁移 |
| `visual.js` | Canvas 物理引擎：十种材质的粒子行为与绘制 |
| `app.js` | 界面交互、状态机、呼吸引导、导入导出 |
| `style.css` | 深夜视觉：幕夜灰到深海蓝的渐变、克制的留白与字距 |

## 六、验证情况

**已验证**：12 项核心检查通过（记录迁移、输入校验、诗译变化、卡片内容、草稿、呼吸阶段，以及全部十种材质在手机与桌面尺寸下的绘制逻辑）；构建产出 5 个自包含静态资源；核心交互已在浏览器中实际操作验证。

**尚未进行**：绘图测试验证的是指令与有限数值，**不等同于真实浏览器的像素或音频测试**；未做完整多浏览器验收与手机真机测试。
