## 一、为什么做 🌫️

### 🧊 失语：不是没有话，是没有一句属于自己的话

得先放下一个误会：失语不是沉默，也不是"不敢讲"。

临床上它有个名字——**精神运动性抑制**（说人话：主管情绪的那部分大脑过载，思维和动作的节奏会一起慢下来）。这个词描述得很准，但它只解释了"说不出来"，没有解释更深的那层困境。

**真正卡住的不是喉咙，是词语。**

现代生活把语言训练成了一种工具。一句话要**有用**——要能推进事情、交换信息、解决问题、得出结论。久而久之，我们能说的话只剩下两类：要么是**有用的**（汇报、解释、请求、安排），要么是**安全的**（玩笑、自嘲、没关系、都挺好）。

而痛苦既没用，也不安全。它不指向任何解决方案，它只是想要被说出来。于是有了那个悖论：

> **最需要被说出口的话，恰恰最没有办法被说。**

现有的语言其实给痛苦留了两个位置，但两个都不太对：

- 🏥 **病理学的位置**——我抑郁了、我是双相、我有焦虑症。它确实给了你说话的资格，但也要求你先成为一个"病例"：先有诊断，痛苦才被承认。
- 😅 **网络梗的位置**——我 emo 了、我碎了、我要发疯了。它让痛苦变得可以说出口，代价是同时把它变成了笑料。说出来的那一刻，它就不太算痛苦了。

中间那一大段——具体的、真实的、既不想被诊断也不想被消解的感受——**没有词**。

所以失语不是心里没有话。是**没有一句属于自己的话**。

### 🔒 自反性无能：看得见问题，所以更动不了

如果说失语是语言层面的困境，**自反性无能**就是它下面更硬的那层。

这个词说的是这样一种状态：人们其实**非常清楚**问题出在哪里——清楚到可以一口气讲出来，清楚到能拿它开玩笑；但正因为看得这么清楚，反而确信自己什么都改变不了。而"我改变不了"这个判断，最终会真的让它变成事实。

它很少表现为崩溃或绝望。它通常表现为一种**带着自知的继续**：照常起床、照常上班、照常刷手机、照常跟人开玩笑，只是不再相信任何行动能通向别处。

这对所有"想帮忙"的东西都是个死结——

你让一个处在自反性无能里的人"说出来""迈出第一步""试着求助"，他心里的回答不是抗拒，而是：**我知道，但这没用。**

而更麻烦的是后面这一层：当"说出来"这件事也被证明无效，它就不再是一次普通的失败，而会升级成**对"我果然什么都做不了"的一次确认**。

> **每一次失败的求助，都会加深下一次的沉默。**

于是失语和自反性无能互相加固：说不出来 → 说了也没用 → 更不想说 → 更确信没用。这两层叠在一起，才是"发不出去"真正的形状。

### 🎯 所以，它不能是"又一个让你倾诉的地方"

把这两层放在一起，很多想当然的做法就站不住了：

- 如果失语是语言问题，那**给一个输入框是没用的**——他不缺地方说话，他缺话。
- 如果自反性无能是行动问题，那**喊"加油"是没用的**——他不缺鼓励，他缺的是一个**不需要先相信就能完成**的动作。

显影 因此给自己定了三条规矩：

### 🚫 最后一件它坚持的事：不去病理化

你的感受不是故障。它不需要被修好，也不需要被解释成"某种机制正在运转"的结果。

这也是诗译里那道硬禁令的由来：**禁止心理学黑话，禁止空泛的加油，禁止试图开导用户。** 只允许白描——大雾、重力、窗户、褪色的相片。

第一版文本曾经塞满"认知过载""代偿机制""系统启动成功"这类词。对一个正在失语的人来说，那不是帮助，是**居高临下的第二次审视**——把他的痛苦翻译成一套他听不懂、也没有请求过的术语。

### 🔁 双轨：把不可交换的东西，换成能递出去的形式

如果问题在于"不可交换的东西在我们的语言里没有位置"，那么能做的其实只有一件事：**给它换一种可以流通的形式，但不改变它。**

| | 💜 亲友卡 | 🩺 医生卡（就诊前整理） |
|---|---|---|
| **用的是** | 感性的语言 | 理性的语言 |
| **它不是** | 倾诉 | 求助 |
| **它是** | 一份**边界声明**——我需要你做什么、做到什么程度为止 | 一份**事实摘要**——这段时间在我身上发生了什么 |
| **关键约束** | 每张卡必须包含**一种明确的行动**，不能让收件人看完不知道该做什么 | 只整理事实，不做量表、不下结论、不显得有临床效力 |
| **举例** | 「不用解决问题，陪我待十分钟。」「暂时不用回复，我只是想让你知道。」 | 持续多久、频率如何、是否在恶化、睡眠进食与日常功能、当前用药变化、这次最希望医生帮什么 |

两份都不是治疗。它们只是把同一份痛苦，翻译成两种别人接得住的语言。

## 二、它能做什么 🎛️

| | 功能 | 说明 |
|:--:|---|---|
| 🌫️ | **十种情绪材质** | 雾层、黏连体、褪色残影、细碎干扰、密实重物、悬浮泡影、岩石层理、空洞负空间、水下折射、玻璃断面。每种有独立的运动方式；压迫感影响视觉尺度；系统开启"减少动态效果"或手动暂停时，画面会完全停住 |
| 📜 | **通感诗译** | 每种质感包含多种开头与收尾，结合附加情绪生成克制的感官白描；可以「换一种说法」，也可以直接复制 |
| 🎴 | **双轨转译卡** | 亲友卡可选安静陪伴 / 陪着待一会儿 / 文字沟通 / 具体帮个忙；医生卡只整理填写内容。两种卡都可手动编辑、保留独立草稿，并导出为 PNG 便笺 |
| 🫁 | **呼吸引导** | 轻缓（4/6）与经典（4/4/4）两种节奏；开始、暂停、继续、重置；可选海浪声与阶段提示音。切换页面或离开浏览器自动暂停 |
| 💾 | **本地保存** | 记录迁移、JSON 导出、二次确认清除。**不同域名的浏览器存储互不共享** |

**3.0 的关键改进：**

- 🛟 「想消失」触发确定性的安全确认，高风险内容**不会被随机诗句省略**
- 🤝 亲友卡默认给出明确回复动作，支持系统原生分享
- 🩺 医生卡改为「就诊前事实摘要」，增加日常功能影响字段
- 🔒 默认不持久保存；用户可自行开启本地保存，并获得**共享设备与明文导出提醒**
- 🫁 呼吸练习增加风险提示，并提供**不需要关注呼吸**的落地练习
- 🎚️ 首屏只展示五种常用质感，其余折叠；**选择不再自动生成文字**

### 🔍 那场「挑刺」，是 3.0 的起点

一句评审把整个项目拉回了地面：

> **显影 现在是一个视觉完成度很高的概念样机，但还不是能放心交给真实脆弱用户使用的心理产品。最大缺陷不在审美，而在——它接住了情绪，却没有接住风险。**

### 🔧 关键决策：每一处改动都对应一句具体的否定

| 收到的反馈 | 决策 | 为什么这么改 |
|---|---|---|
| 🪲 「整个 html 应用差强人意」 | 先修工程问题，再谈美学 | 刷新覆盖记录、复制失败却提示成功——这类 Bug 会直接摧毁信任，比"不好看"严重得多 |
| ✂️ 「做个备份，然后大刀阔斧地改，美术也可以大改」 | 完整备份后整体重塑，不打补丁 | 视觉是入口，补丁堆不出质感 |
| 🎨 「需要完全重塑情绪显影的视觉呈现，质感要一致」 | 十种独立材质，各自独立的运动方式 | 廉价屏保感的粒子，承载不起"被看见"这件事 |
| 🪨 「褪色、噪点，尤其是沉重，效果太差」 | 三个重做 | 名不副实的材质，比没有更糟 |
| 🧪 「噪点根本就不是噪点，胶水也不太行」 | 噪点去掉波形改独立颗粒；胶水加拉开、拉丝、下垂、回缩 | 用户说的是**名实不符**，不是"不够好看"——要改的是物理，不是配色 |
| 💬 「双轨传译太生硬」 | 标签转日常表达，去掉报数、模板腔和感谢套话 | 生硬的关心比不关心更伤人 |

## 四、它不做什么 🚧

- 🚫 **不提供诊断、治疗或紧急服务。** 这是工具，不是医疗服务。
- 📊 **不做心理量表，不输出任何分数或评估结论。** 医生卡只整理你填写的内容。
- 🫂 **不去病理化你的感受。** 它不认为你是故障，也不会把你的痛苦翻译成术语。
- 🫁 **呼吸练习有适用边界。** 出现头晕、胸痛、呼吸困难请立即停止；也提供不需要关注呼吸的替代练习。
- 💾 **默认不持久保存。** 你可自行开启本地保存，届时会收到共享设备与明文导出的提醒。
- 📤 **导出的 JSON 与 PNG 是明文。** 不要发到不放心的地方。
- 🌐 **不同域名的浏览器存储互不共享。**
- 🔌 **无第三方脚本、字体或图片请求**，也不发任何埋点。断网也能用。

## 五、运行与部署 🚀

纯静态网页，**打开 `index.html` 就能用**，不需要构建、不需要服务器、不需要安装任何依赖。

（唯一例外：复制功能需要 HTTPS 或 localhost 环境，以及浏览器授权。）

需要 Node.js 18 或以上，但**不需要 `npm install`**：

```sh
node test.cjs    # 12 项核心逻辑检查
node build.cjs   # 构建，产物在 dist/
```

`dist/` 是可以直接部署的静态输出。
