# EchoGlow · 回声微光 / Studio

在原有情绪显影、双轨转译、呼吸引导基础上的完整重设计。纯静态网页，无第三方脚本、字体或图片请求；打开 `index.html` 即可使用。复制需要 HTTPS / localhost 和浏览器授权。

## 功能

- 十种独立的情绪材质：雾层、黏连体、褪色残影、细碎干扰、密实重物、悬浮泡影、岩石层理、空洞负空间、水下折射、玻璃断面。压迫感影响视觉尺度，系统减少动态效果或手动暂停会停止画面运动。
- 每种质感包含多种开头与收尾，结合附加情绪生成通感诗译；可换一种说法或复制。
- 亲友卡允许选择安静、陪伴、文字沟通或具体帮助；医生卡只整理填写内容。两种卡均可手动编辑，保留独立草稿，并导出完整 PNG 便笺。
- 轻缓（4/6）与经典（4/4/4）呼吸节奏；开始、暂停、继续、重置；可选海浪声与阶段提示音。切换页面或离开浏览器自动暂停。
- 本地保存、旧版记录迁移、JSON 记录导出与二次确认清除。不同域名的浏览器存储互不共享，线上新域名无法自动读取 GitHub Pages 或本地文件的记录。

## 验证与构建

需要 Node.js 18 或以上，不需要安装依赖：

```sh
node test.cjs
node build.cjs
```

`dist/` 是可部署的静态输出。测试覆盖记录迁移、输入校验、诗译变化、卡片内容、草稿、呼吸阶段，以及所有材质在手机和桌面尺寸下的绘制逻辑。绘图测试验证指令与有限数值，不等同于真实浏览器的像素或音频测试。

备份在上一级目录的 `EchoGlow-backup-*.zip`，上一版 `EchoGlow/` 也保留不动。新版使用独立的本地存储键，迁移时不会覆盖旧版记录。
